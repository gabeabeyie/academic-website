GABRIEL A. ABEYIE — ACADEMIC WEBSITE

Open index.html in your browser to view the homepage. Research, Teaching,
and Contact are separate pages. No installation or build is required.

PUBLISH TO YOUR EXISTING GITHUB PAGES SITE
1. Unzip this package.
2. Upload index.html, research.html, teaching.html, contact.html, styles.css,
   and the assets folder to the root of your academic-website repository.
3. Keep the existing CV, paper PDFs, syllabus, evaluation PDFs, and favicon.
   Their existing URLs are used throughout the site.
4. Commit the changes. Your existing GitHub Pages setup can serve these files.

EDITING
- Home: index.html
- Research titles, statuses, links, and abstracts: research.html
- Course descriptions and records: teaching.html
- Contact information: contact.html
- Colors, typography, and responsive layout: styles.css
- Portrait: assets/portrait.jpg

The separate academic-website-preview.html is a convenient single-file
review copy. Upload the files in this package when publishing the full site.

CONTENT
Research statuses and teaching records were carried forward from your supplied
website. Review items such as forthcoming evaluations when you update content.
No new journal outcomes, credentials, or publication claims were added.

ACCESSIBILITY
Semantic landmarks, labeled navigation, native expandable abstracts, visible
keyboard focus, reduced-motion support, and responsive layout are included.
The hosted pages require no JavaScript. Text contrast and source structure
were checked; a full rendered-browser audit has not been completed.
